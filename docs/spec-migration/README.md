# Archiv der Baseline-Migration

Arbeitsverzeichnis der Dokumentationsmigration vom 2026-10-23. Die Dateien belegen, **woher** jede Anforderung und jeder Entscheid stammt. Sie werden nicht mehr gepflegt; gültig sind `openspec/specs/` und `docs/adr/`.

| Datei | Inhalt |
|---|---|
| `00-inventory.md` | Inventar aller Anforderungen (R-xxx) und Entscheide (D-xxx) mit Quelle, Herkunft, Zustand und Konflikten (K-001…K-021, alle gelöst) |
| `history.md` | Geänderte Anforderungen im Projektverlauf (H-01…H-24) |
| `02-domains.md` | Aufteilung in 17 Domains und Zuordnung der Inventar-IDs |
| `OPEN-QUESTIONS.md` | Offene Fragen Q-001…Q-010 mit Antworten (alle beantwortet) |
| `COVERAGE.md` | Abdeckung von README, Verzeichnissen und Inventar durch Specs und ADRs |
| `PROGRESS.md` | Phasen, Zahlen und Entscheide der Konfliktklärung |

Die IDs in den Zeilen `Inventar:` der Specs und ADRs verweisen auf `00-inventory.md`.
