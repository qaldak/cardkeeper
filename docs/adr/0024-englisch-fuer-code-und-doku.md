# ADR 0024: Code-Kommentare und README auf Englisch

- **Status:** Akzeptiert
- **Datum:** 2026-10-04
- **Herkunft:** User-Vorgabe (Chat 2026-10-04 09:59).
- **Specs:** [`entwicklung-release`](../../openspec/specs/entwicklung-release/spec.md), [`oberflaeche`](../../openspec/specs/oberflaeche/spec.md)

## Kontext

Der Benutzer schreibt auf Deutsch und legte die Sprache für Code-Kommentare und README zu Beginn fest.

## Entscheid

Der Benutzer legte fest: „Bitte verwende für kommentare ausschliesslich englisch. auch für das readme.“ Die Oberfläche selbst ist zweisprachig (Deutsch/Englisch).

## Betrachtete Alternativen

nicht dokumentiert.

## Konsequenzen

- Die README und Code-Kommentare sind englisch; die Konzept- und Spezifikationsdokumente dieser Baseline sind auf Deutsch (Vorgabe des Auftrags).
