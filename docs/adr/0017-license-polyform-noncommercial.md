# ADR 0017: License PolyForm Noncommercial 1.0.0

- **Status:** Accepted
- **Date:** 2026-10-07
- **Origin:** User requirement (User instruction 2026-10-07 15:31, 15:53).
- **Specs:** [`development-release`](../../openspec/specs/development-release/spec.md)

## Context

The repository was started with the AGPL v3 (initial commit of the user, Git `27da236`). On 2026-10-07 15:31 the user requested to change the license afterwards to PolyForm Noncommercial 1.0.0 ("correct texts"); at 15:53: "Currently polyform-noncommercial is probably the right one."

## Decision

The application is under the PolyForm Noncommercial License 1.0.0 (private use, hobby, research, education, charitable organisations; no commercial use), with a `NOTICE`. The change was made on a separate branch.

## Considered alternatives

- Keeping the AGPL v3 (starting point, replaced).
- A "contribution welcome" notice or a contribution rule: the assistant asked, the user decided "then let's leave it out" (2026-10-07 15:51–15:53).

## Consequences

- Earlier versions remain available under the AGPL v3 for everybody who received them (README).
- The license is not an open-source license in the sense of the OSI (README).
