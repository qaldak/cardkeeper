## Kontext

Das Repository wurde mit der AGPL v3 begonnen (Initial commit des Benutzers, Git `27da236`). Am 2026-10-07 15:31 verlangte der Benutzer, die Lizenz nachträglich auf PolyForm Noncommercial 1.0.0 zu ändern („korrekte Texte“); um 15:53: „Aktuell ist polyform-noncommercial wohl das richtige.“

## Entscheid

Die Anwendung steht unter der PolyForm Noncommercial License 1.0.0 (private Nutzung, Hobby, Forschung, Bildung, gemeinnützige Organisationen; keine kommerzielle Nutzung), mit `NOTICE`. Die Änderung erfolgte auf einem eigenen Branch.

## Betrachtete Alternativen

- Beibehalten der AGPL v3 (Ausgangslage, abgelöst).
- Ein Hinweis „contribution welcome“ bzw. eine Beitragsregelung: der Assistent fragte, der Benutzer entschied „dann lassen wir’s mal weg“ (2026-10-07 15:51–15:53).

## Konsequenzen

- Frühere Versionen bleiben unter der AGPL v3 für alle verfügbar, die sie erhalten haben (README).
- Die Lizenz ist keine Open-Source-Lizenz im Sinne der OSI (README).
